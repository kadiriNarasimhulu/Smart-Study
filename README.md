# 🎓 Smart Study

Smart Study is a simple desktop study application designed to help students learn, plan, and track their progress.

## ✨ Features

- 📚 Subject Management
- 📝 Quiz
- 📅 Study Planner
- ⏱️ Focus Timer
- 📊 Progress Tracking
- 🔥 Daily Challenges
- ⭐ XP and Study Progress
